Enterprise CI/CD agenti i deployment okruzenja su cesto Linux masine — poznavanje osnovnih komandi je korisno za debugovanje pipeline-a i provere okruzenja bez oslanjanja na DevOps tim za svaku sitnicu.

24.1 Logovi i pretraga

grep -i "error" /var/log/app.log     # trazi "error" bez obzira na velika/mala slova
tail -f /var/log/app.log             # prati log u realnom vremenu (novi redovi odmah vidljivi)
tail -f log.txt | grep -i "error"    # filtrira live log samo na greske
cat / head / tail / wc -l            # citanje fajla / pocetak / kraj / broj redova
find / -name "*.log"                 # pronadji sve .log fajlove na sistemu

24.2 Procesi i servisi

ps aux | grep service_name    # da li servis/proces radi
systemctl status service_name # status servisa (running/failed/stopped)
top / htop                    # procesi uzivo, CPU/RAM po procesu

24.3 Resursi i dozvole

df -h            # slobodan prostor na disku (cest uzrok "environment down" incidenata)
free -h          # iskoriscenost memorije
chmod 755 script.sh   # owner: read+write+execute, ostali: read+execute
Cest scenario: CI pipeline pocne da failuje bez promene u kodu — pre nego sto se sumnja na test, proveriti df -h (disk pun na agentu) i systemctl status za servise od kojih pipeline zavisi (baza, mock servisi).
