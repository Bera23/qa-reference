25.14 Alat i protokol poredjenja

PoredjenjeKljucna razlika
Selenium vs. PlaywrightSelenium — zreo, svi jezici, rucno podesavanje wait-ova. Playwright — noviji, auto-wait, ugradjeno upravljanje browser-ima, network interception. Oba podrzavaju POM.
Cypress vs. PlaywrightCypress — samo JS, izvrsava se unutar browsera, jedan tab. Playwright — vise jezika, vise browsera, vise tabova, bolji za kompleksne aplikacije.
REST vs. SOAPREST — HTTP, JSON, lagan. SOAP — XML, strogi kontrakti, ugradjena bezbednost. REST dominira modernim API-jima, SOAP jos zivi u enterprise/banking sistemima.
REST vs. GraphQLREST — jedan endpoint po resursu, server odredjuje oblik odgovora. GraphQL — jedan endpoint, klijent sam bira koja polja zeli.
