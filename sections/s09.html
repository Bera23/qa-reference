9.1 Tipovi test izvestaja

Test Execution ReportOperativni — pise se tokom ili odmah nakon izvrsavanja testova. Namenjen QA timu i tech lead-u.
Test Summary ReportTakticki — pise se na kraju test ciklusa ili sprinta. Namenjen timu i project manager-u.
Test Closure ReportStrateski — pise se na kraju release-a. Namenjen stakeholderima i menadzmentu.

9.4 Kako prezentovati QA status stakeholderima

Lose:
  'Izvrsili smo 47 TC-ova, 41 je proslo, 4 failovala, 2 blocked.'

Dobro:
  'Sistem je stabilan i spreman za release uz jedan rizik koji
   zahteva vasu odluku: postoje 2 Minor defekta na checkout stranici
   koji se javljaju samo na Safari browser-u (3% nasih korisnika).
   Preporuka: releasovati sada, fiksirati u hotfix-u sledece nedelje.'

Princip: QA daje cinjenice + preporuku + opcije. Stakeholder donosi odluku.

9.5 Azure DevOps Test Plans — kljucne funkcionalnosti

FunkcionalnostOpis
Test PlansKontejner za organizovanje test suite-ova po release-u ili sprintu.
Test SuitesGrupisanje TC-ova po modulu, funkcionalnosti ili tipu (regression, smoke).
Test CasesWork item tip koji cuva korake, expected result, attachments.
Test RunsIzvrsavanje test suite-a — belezi ko je izvrsio, kada i sa kojim rezultatom.
ChartsVizuelizacija rezultata — pie chart pass/fail, trend kroz vreme.
TraceabilityDirektna veza izmedju Test Case work item-a i User Story / Bug work item-a.
