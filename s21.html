21.1 Sta je Appium i kako funkcionise

Appium je open-source alat za automatizaciju mobilnih aplikacija. Koristi WebDriver protokol — ista arhitektura kao Selenium, ali sa mobilnim driver-ima.

  [Test kod (C#/Java/Python)]
          |  WebDriver API pozivi
          v
  [Appium Server]
          |  XCUITest (iOS) / UIAutomator2 (Android)
          v
  [Realni uredjaj / Emulator]

21.3 Appium C# — setup i osnovni test

// Capabilities i driver inicijalizacija (Android)
var options = new AppiumOptions();
options.PlatformName = "Android";
options.AutomationName = "UIAutomator2";
options.DeviceName = "emulator-5554";
options.App = "/path/to/app.apk";

var driver = new AndroidDriver(
    new Uri("http://localhost:4723"), options);

// Lociranje elementa i interakcija
var loginBtn = driver.FindElement(
    MobileBy.AccessibilityId("loginButton"));
loginBtn.Click();

// Assertion (xUnit)
var welcomeMsg = driver.FindElement(
    MobileBy.AccessibilityId("welcomeLabel"));
Assert.Equal("Dobrodosli", welcomeMsg.Text);
Ista WebDriver arhitektura kao Selenium (videti Sekciju 13) — poznavanje lokator strategija i wait mehanizama se direktno prenosi.

21.5 Gesture akcije u C#

// Swipe gore (scroll down)
var size = driver.Manage().Window.Size;
var finger = new PointerInputDevice(PointerKind.Touch, "finger");
var swipe = new ActionSequence(finger);
swipe.AddAction(finger.CreatePointerMove(
    CoordinateOrigin.Viewport, size.Width / 2, size.Height * 3 / 4));
swipe.AddAction(finger.CreatePointerDown(MouseButton.Left));
swipe.AddAction(finger.CreatePointerMove(
    CoordinateOrigin.Viewport, size.Width / 2, size.Height / 4,
    TimeSpan.FromMilliseconds(500)));
swipe.AddAction(finger.CreatePointerUp(MouseButton.Left));
driver.PerformActions(new List<ActionSequence> { swipe });

// Tap na koordinate
var tap = new ActionSequence(finger);
tap.AddAction(finger.CreatePointerMove(
    CoordinateOrigin.Viewport, 200, 400));
tap.AddAction(finger.CreatePointerDown(MouseButton.Left));
tap.AddAction(finger.CreatePointerUp(MouseButton.Left));
driver.PerformActions(new List<ActionSequence> { tap });

21.6 Page Object Model za mobilne aplikacije

// POM za Appium — isti princip kao web (videti Sekciju 14)
public class LoginScreen
{
 private readonly AndroidDriver _driver;

 private AppiumElement UsernameField =>
  _driver.FindElement(MobileBy.AccessibilityId("username"));
 private AppiumElement PasswordField =>
  _driver.FindElement(MobileBy.AccessibilityId("password"));
 private AppiumElement LoginButton =>
  _driver.FindElement(MobileBy.AccessibilityId("loginBtn"));

 public LoginScreen(AndroidDriver driver) => _driver = driver;

 public HomeScreen LoginAs(string user, string pass)
 {
  UsernameField.SendKeys(user);
  PasswordField.SendKeys(pass);
  LoginButton.Click();
  return new HomeScreen(_driver);
 }
}

21.7 Realni uredaji vs. Emulatori

Emulatori / SimulatoriRealni uredaji
Brzina setup-aBrzo, bez hardveraZahteva fizicki pristup
TacnostDobra za funkcionalne testoveNeophodna za hardware, senzore, performanse
CenaBesplatnoKupovina ili cloud (BrowserStack, Sauce Labs)
InterruptionsNe simulira pozive, SMSRealni interruptions
PreporukaRegression, funkcionalni testoviRelease testing, performance, UAT
Cloud device farme (BrowserStack, Sauce Labs, AWS Device Farm) nude stotine realnih uredaja bez kupovine — idealno za cross-device testing.

21.8 Specificnosti mobilnog testiranja

  • Razlicite rezolucije i gustine piksela — testirati na vise uredjaja.
  • Interruptions: pozivi, notifikacije, low battery — sistem mora da se ponasa predvidivo.
  • Network conditions — testirati na 3G, 4G, offline modu.
  • Permissions — kamera, lokacija, kontakti — testirati scenarije odbijanja dozvola.
  • Orientation — portrait i landscape mod.
