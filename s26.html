DEO II — AUTOMATSKO TESTIRANJE

⌨️ 26. Live coding (C#)✓ Procitano

⏱ ~20 min citanja

Live coding u QA automation intervjuu retko je tezak algoritam. Proverava se da li pod pritiskom pises citljiv C#, da li razmisljas naglas i da li testiras sopstveni kod. Ispod su najcesci zadaci (FizzBuzz, obrtanje stringa, duplikati...), grupisani, sa resenjem, edge case-ovima i tipicnim potpitanjem.

Svi primeri pretpostavljaju using System; using System.Collections.Generic; using System.Linq; using System.Text; using System.Threading; i da se metode nalaze u statickoj klasi Solutions. Sva resenja su kompajlirana i pokrenuta (.NET 8) nad test primerima, ukljucujuci edge case-ove. Komentari u kodu su na engleskom, kao u pravom projektu.

26.3 Brojevi i petlje

FizzBuzz

Zadatak: Za brojeve od 1 do 100 ispisi "Fizz" za umnoske broja 3, "Buzz" za umnoske broja 5 i "FizzBuzz" za umnoske oba; za ostale sam broj.

public static string FizzBuzz(int n)
{
    // Check the combined case first, otherwise 15 would stop at the Fizz branch
    if (n % 15 == 0) return "FizzBuzz";
    if (n % 3 == 0) return "Fizz";
    if (n % 5 == 0) return "Buzz";
    return n.ToString();
}

// Variant that is easy to extend when the interviewer adds a rule (for example 7 = Bazz)
public static string FizzBuzzConcat(int n)
{
    string result = "";
    if (n % 3 == 0) result += "Fizz";
    if (n % 5 == 0) result += "Buzz";
    return result.Length == 0 ? n.ToString() : result;
}
Klasicna zamka je redosled: kombinovani slucaj (n % 15) mora prvi. Ispis je petlja for (int i = 1; i <= 100; i++) koja poziva metodu. Druga varijanta se lakse prosiruje, pa je dobar odgovor na pitanje "sta ako dodam jos jedno pravilo?".

Da li je broj prost

Zadatak: Napisi metodu koja vraca true ako je broj prost. Primer: 7 je prost, 9 nije, 1 i negativni brojevi nisu.

public static bool IsPrime(int n)
{
    if (n < 2) return false;
    // Only divisors up to the square root need to be checked
    // The long cast prevents overflow of i * i for values close to int.MaxValue
    for (int i = 2; (long)i * i <= n; i++)
    {
        if (n % i == 0) return false;
    }
    return true;
}
Naivno resenje (deljenje do n - 1) je O(n); do korena je O(sqrt n). Edge case-ovi koje intervjuer voli: 0, 1, 2 (jedini paran prost) i negativni brojevi.

Zbir cifara

Zadatak: Vrati zbir cifara celog broja. Primer: 1234 daje 10.

public static int SumOfDigits(int n)
{
    // Math.Abs would throw for int.MinValue, so widen to long first
    long value = Math.Abs((long)n);
    int sum = 0;
    while (value > 0)
    {
        sum += (int)(value % 10);
        value /= 10;
    }
    return sum;
}
Modulo 10 daje poslednju cifru, deljenje sa 10 je odsece. Pitanje "sta sa negativnim brojem?" je cesto; Math.Abs(int.MinValue) baca OverflowException, zato prvo prosirenje na long.

Zameni dve promenljive bez trece

Zadatak: Zameni vrednosti dva cela broja bez pomocne (temp) promenljive.

public static void Swap(ref int a, ref int b)
{
    // Tuple deconstruction (C# 7+): the usual modern answer
    (a, b) = (b, a);
}

public static void SwapXor(ref int a, ref int b)
{
    // XOR swap: no third variable and no overflow
    // Breaks if both parameters refer to the same variable (the value becomes 0)
    a ^= b;
    b ^= a;
    a ^= b;
}
Stara varijanta a = a + b; b = a - b; a = a - b; radi, ali moze da preplavi int. Intervjuer obicno trazi da znas zasto je XOR bezbedniji od sabiranja.

Fibonacci (n-ti clan)

Zadatak: Vrati n-ti Fibonacci broj (0, 1, 1, 2, 3, 5, 8, ...). F(0) = 0, F(1) = 1.

public static long Fibonacci(int n)
{
    if (n < 0) throw new ArgumentOutOfRangeException(nameof(n));
    long previous = 0, current = 1;
    // After n steps, previous holds F(n)
    for (int i = 0; i < n; i++)
    {
        long next = previous + current;
        previous = current;
        current = next;
    }
    return previous;
}
Iterativno resenje je O(n) vreme i O(1) memorija. Rekurzivno F(n-1) + F(n-2) je O(2^n) i zato se pita "zasto je sporo?". long preplavljuje kod n = 93.

26.4 Stringovi

Obrni string

Zadatak: Vrati string u obrnutom redosledu. Primer: "hello" daje "olleh".

public static string ReverseString(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    char[] chars = input.ToCharArray();
    Array.Reverse(chars);
    return new string(chars);
}

// Manual version: two pointers swap characters from both ends, O(n) time
public static string ReverseManual(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    char[] chars = input.ToCharArray();
    int left = 0, right = chars.Length - 1;
    while (left < right)
    {
        (chars[left], chars[right]) = (chars[right], chars[left]);
        left++;
        right--;
    }
    return new string(chars);
}
Ako kazu "bez ugradjenih metoda", ide rucna verzija. Zamke: result += c u petlji je O(n^2) (koristi StringBuilder ili char niz), a obrtanje po char-u lomi surrogate parove (emoji); za pun Unicode treba StringInfo / TextElementEnumerator.

Palindrom

Zadatak: Proveri da li je tekst palindrom, ignorisuci velika/mala slova i znakove koji nisu slova ili cifre. Primer: "A man, a plan, a canal: Panama" je palindrom.

public static bool IsPalindrome(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    int left = 0, right = input.Length - 1;
    while (left < right)
    {
        // Skip characters that are not letters or digits
        if (!char.IsLetterOrDigit(input[left])) { left++; continue; }
        if (!char.IsLetterOrDigit(input[right])) { right--; continue; }
        if (char.ToLowerInvariant(input[left]) != char.ToLowerInvariant(input[right])) return false;
        left++;
        right--;
    }
    return true;
}
Dva pokazivaca ne prave novi string (O(1) memorija), za razliku od "obrni pa uporedi". Prvo pitaj da li se razmaci, interpunkcija i velika slova ignorisu. Edge case-ovi: prazan string, jedan znak i tekst od samih znakova interpunkcije.

Obrni redosled reci

Zadatak: Obrni redosled reci u recenici. Primer: "the sky is blue" daje "blue is sky the".

public static string ReverseWords(string sentence)
{
    if (sentence == null) throw new ArgumentNullException(nameof(sentence));
    // RemoveEmptyEntries also collapses repeated and leading/trailing spaces
    string[] words = sentence.Split(new[] { ' ' }, StringSplitOptions.RemoveEmptyEntries);
    Array.Reverse(words);
    return string.Join(" ", words);
}
Cesta greska: Split(' ') bez RemoveEmptyEntries ostavlja prazne reci kad ima duplih razmaka. Pitanje za intervjuera: ostaju li viskovi razmaka ili se skupljaju?

Prebroj samoglasnike

Zadatak: Vrati broj samoglasnika u stringu. Primer: "Beautiful" daje 5.

public static int CountVowels(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    const string vowels = "aeiouAEIOU";
    int count = 0;
    foreach (char c in input)
    {
        if (vowels.IndexOf(c) >= 0) count++;
    }
    return count;
}
LINQ varijanta: input.Count(c => "aeiouAEIOU".Contains(c)). Pitaj da li se "y" racuna i da li je poredjenje case-sensitive; alternativa je char.ToLowerInvariant pa jedan skup malih slova.

Ucestalost znakova

Zadatak: Prebroj koliko se puta svaki znak pojavljuje u stringu. Primer: "hello" daje h:1, e:1, l:2, o:1.

public static Dictionary<char, int> CharFrequency(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    var counts = new Dictionary<char, int>();
    foreach (char c in input)
    {
        // TryGetValue leaves current at 0 when the key is missing
        counts.TryGetValue(c, out int current);
        counts[c] = current + 1;
    }
    return counts;
}

// LINQ variant: shorter, same result
public static Dictionary<char, int> CharFrequencyLinq(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    return input.GroupBy(c => c).ToDictionary(g => g.Key, g => g.Count());
}
Ovaj obrazac (TryGetValue pa upis) je osnova za skoro sve zadatke o duplikatima. counts[c]++ baca KeyNotFoundException za novi kljuc, pa se ne koristi bez provere. Da li je "a" isto sto i "A" je pitanje koje treba postaviti.

Prvi znak koji se ne ponavlja

Zadatak: Vrati prvi znak koji se u stringu pojavljuje tacno jednom, ili null ako takvog nema. Primer: "swiss" daje "w".

public static char? FirstNonRepeatingChar(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    var counts = new Dictionary<char, int>();
    foreach (char c in input)
    {
        counts.TryGetValue(c, out int current);
        counts[c] = current + 1;
    }
    // A second pass over the input keeps the original order
    foreach (char c in input)
    {
        if (counts[c] == 1) return c;
    }
    return null;
}
Dva prolaza, O(n) vreme i memorija. Vracanje char? je bolje od "magicne" vrednosti kao sto je '\0'. Redosled se cuva prolaskom kroz originalni string, a ne kroz recnik.

Anagrami

Zadatak: Proveri da li su dva stringa anagrami (isti znaci u drugom redosledu). Primer: "listen" i "silent" jesu, "hello" i "world" nisu.

public static bool AreAnagrams(string first, string second)
{
    if (first == null || second == null) return false;
    if (first.Length != second.Length) return false;
    var counts = new Dictionary<char, int>();
    foreach (char c in first)
    {
        counts.TryGetValue(c, out int current);
        counts[c] = current + 1;
    }
    foreach (char c in second)
    {
        // A missing or exhausted letter means the strings differ
        if (!counts.TryGetValue(c, out int current) || current == 0) return false;
        counts[c] = current - 1;
    }
    return true;
}
Alternativa je sortiranje oba stringa pa poredjenje (first.OrderBy(c => c).SequenceEqual(second.OrderBy(c => c))), kratko ali O(n log n). Provera duzine na pocetku je jeftin izlaz. Pitaj: case-sensitive? Razmaci se ignorisu?

Kompresija stringa (run-length)

Zadatak: Kompresuj uzastopne znakove u znak i broj ponavljanja. Primer: "aabcccccaaa" daje "a2b1c5a3".

public static string CompressString(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    if (input.Length == 0) return input;
    var result = new StringBuilder();
    int runLength = 1;
    for (int i = 1; i <= input.Length; i++)
    {
        // The extra final iteration flushes the last run
        if (i < input.Length && input[i] == input[i - 1])
        {
            runLength++;
        }
        else
        {
            result.Append(input[i - 1]).Append(runLength);
            runLength = 1;
        }
    }
    return result.ToString();
}
Trik je da petlja ide do i <= input.Length kako bi se poslednja serija upisala. Za "abc" rezultat je "a1b1c1", duzi od originala; cest je dodatni zahtev "vrati original ako kompresija nije kraca". StringBuilder umesto += je poenta zadatka.

Ukloni duplirane znakove

Zadatak: Ukloni ponovljene znakove, zadrzavajuci prvo pojavljivanje i redosled. Primer: "programming" daje "progamin".

public static string RemoveDuplicateChars(string input)
{
    if (input == null) throw new ArgumentNullException(nameof(input));
    var seen = new HashSet<char>();
    var result = new StringBuilder();
    foreach (char c in input)
    {
        // HashSet.Add returns false when the element is already present
        if (seen.Add(c)) result.Append(c);
    }
    return result.ToString();
}
HashSet.Add istovremeno proverava i dodaje, pa nema posebnog Contains. LINQ jednolinijsko: new string(input.Distinct().ToArray()).

26.5 Nizovi i duplikati

Pronadji duplikate u nizu

Zadatak: Vrati vrednosti koje se u nizu pojavljuju vise od jednom (svaku samo jednom). Primer: { 1, 2, 3, 2, 4, 5, 5 } daje { 2, 5 }.

public static List<int> FindDuplicates(int[] numbers)
{
    if (numbers == null) throw new ArgumentNullException(nameof(numbers));
    var seen = new HashSet<int>();
    var duplicates = new HashSet<int>();
    foreach (int n in numbers)
    {
        // Add returns false on the second and every later occurrence
        if (!seen.Add(n)) duplicates.Add(n);
    }
    return duplicates.ToList();
}
Jedan prolaz, O(n) vreme i memorija. Naivno resenje sa dve petlje je O(n^2), i to je tipican "prvi pokusaj" koji intervjuer trazi da poboljsas. LINQ: numbers.GroupBy(x => x).Where(g => g.Count() > 1).Select(g => g.Key). Redosled rezultata nije garantovan.

Prebroj duplikate

Zadatak: Za svaku vrednost koja se ponavlja vrati koliko se puta pojavljuje. Primer: { 1, 2, 3, 2, 4, 5, 5, 5 } daje 2 puta 2 i 3 puta 5.

public static Dictionary<int, int> CountDuplicates(int[] numbers)
{
    if (numbers == null) throw new ArgumentNullException(nameof(numbers));
    return numbers
        .GroupBy(n => n)
        .Where(group => group.Count() > 1)
        .ToDictionary(group => group.Key, group => group.Count());
}

// Manual version with a Dictionary, same result
public static Dictionary<int, int> CountDuplicatesManual(int[] numbers)
{
    if (numbers == null) throw new ArgumentNullException(nameof(numbers));
    var counts = new Dictionary<int, int>();
    foreach (int n in numbers)
    {
        counts.TryGetValue(n, out int current);
        counts[n] = current + 1;
    }
    // Keep only the values seen more than once
    return counts
        .Where(pair => pair.Value > 1)
        .ToDictionary(pair => pair.Key, pair => pair.Value);
}
Ovo je uopstenje zadatka iznad: umesto bool cuvamo broj pojavljivanja. LINQ verzija je kratka, a rucna pokazuje da razumes sta GroupBy radi ispod haube. Ako trebaju samo vrednosti sa najvecim brojem ponavljanja, dodaj OrderByDescending(pair => pair.Value).

Ukloni duplikate iz niza

Zadatak: Vrati niz bez duplikata, zadrzavajuci redosled prvog pojavljivanja. Primer: { 3, 1, 3, 2, 1 } daje { 3, 1, 2 }.

public static int[] RemoveDuplicates(int[] numbers)
{
    if (numbers == null) throw new ArgumentNullException(nameof(numbers));
    var seen = new HashSet<int>();
    var result = new List<int>();
    foreach (int n in numbers)
    {
        if (seen.Add(n)) result.Add(n);
    }
    return result.ToArray();
}
Jednolinijsko je numbers.Distinct().ToArray(). U praksi cuva redosled prvog pojavljivanja, ali dokumentacija to ne garantuje, dok rucna verzija garantuje. Ako je niz vec sortiran, dovoljan je jedan prolaz sa dva pokazivaca bez dodatne memorije.

Drugi najveci element

Zadatak: Vrati drugi najveci (razlicit od najveceg) element bez sortiranja, ili null ako ne postoji. Primer: { 3, 1, 4, 1, 5, 9 } daje 5.

public static int? SecondLargest(int[] numbers)
{
    if (numbers == null) throw new ArgumentNullException(nameof(numbers));
    int? largest = null;
    int? second = null;
    foreach (int n in numbers)
    {
        if (largest == null || n > largest)
        {
            second = largest;
            largest = n;
        }
        // Strictly smaller than largest: equal values must not count as the second largest
        else if (n < largest && (second == null || n > second))
        {
            second = n;
        }
    }
    return second;
}
Jedan prolaz, O(n), bez sortiranja (koje je O(n log n)). Edge case-ovi: niz od jednog elementa, svi elementi isti ({ 5, 5, 5 } nema drugi najveci) i negativni brojevi. Zato je povratni tip int?.

Nedostajuci broj od 1 do N

Zadatak: Niz sadrzi brojeve od 1 do N, ali jedan nedostaje. Pronadji ga. Primer: { 1, 2, 4, 5 } za N = 5 daje 3.

public static int FindMissingNumber(int[] numbers, int n)
{
    if (numbers == null) throw new ArgumentNullException(nameof(numbers));
    // Sum of 1..n by the arithmetic series formula; long avoids overflow for large n
    long expectedSum = (long)n * (n + 1L) / 2;
    long actualSum = 0;
    foreach (int value in numbers) actualSum += value;
    return (int)(expectedSum - actualSum);
}
Formula n * (n + 1) / 2 daje O(n) vreme i O(1) memoriju, bez sortiranja i skupa. Radi samo kad nedostaje tacno jedan broj; ako ih moze nedostajati vise, koristi HashSet. Alternativa je XOR svih brojeva.

Two Sum

Zadatak: Vrati indekse dva elementa ciji je zbir jednak cilju. Primer: { 2, 7, 11, 15 } i cilj 9 daje indekse 0 i 1.

public static int[] TwoSum(int[] numbers, int target)
{
    if (numbers == null) throw new ArgumentNullException(nameof(numbers));
    // Maps a value to the index where it was seen
    var seen = new Dictionary<int, int>();
    for (int i = 0; i < numbers.Length; i++)
    {
        int complement = target - numbers[i];
        if (seen.TryGetValue(complement, out int j)) return new[] { j, i };
        // Assign instead of Add so a repeated value does not throw
        seen[numbers[i]] = i;
    }
    return Array.Empty<int>();
}
Naivno su dve ugnjezdene petlje, O(n^2). Recnik daje O(n) tako sto za svaki element trazi njegov komplement medju vec vidjenima. Pitanja: moze li isti element dva puta? sta ako ima vise parova? sta ako nema nijednog (ovde prazan niz)?

Pomeri nule na kraj

Zadatak: Pomeri sve nule na kraj niza (u istom nizu), ocuvavsi redosled ostalih elemenata. Primer: { 0, 1, 0, 3, 12 } postaje { 1, 3, 12, 0, 0 }.

public static void MoveZeroesToEnd(int[] numbers)
{
    if (numbers == null) throw new ArgumentNullException(nameof(numbers));
    // insertAt is the next slot for a non-zero value
    int insertAt = 0;
    for (int i = 0; i < numbers.Length; i++)
    {
        if (numbers[i] != 0)
        {
            numbers[insertAt] = numbers[i];
            insertAt++;
        }
    }
    // Everything after the last non-zero value becomes zero
    for (int i = insertAt; i < numbers.Length; i++)
    {
        numbers[i] = 0;
    }
}
In-place resenje: O(n) vreme i O(1) memorija, bez novog niza. Ovo je obrazac dva pokazivaca (citanje i upis) koji se pojavljuje u mnogo zadataka. Cesto pitanje je da li se redosled nenultih elemenata mora ocuvati (ovde da).

26.6 Zadaci iz QA prakse

Kod QA automation pozicija cesto dobijes zadatak koji lici na tvoj svakodnevni posao, ne cist algoritam. Ova cetiri pokrivaju provere UI-ja, poredjenje podataka, izvestaje i stabilnost testova.

Da li je kolona sortirana (assert nad UI grid-om)

Zadatak: Proveri da li su vrednosti (npr. tekst jedne kolone grid-a) sortirane rastuce ili opadajuce. Ovo je svakodnevni QA zadatak: test klikne zaglavlje kolone pa proverava redosled.

public static bool IsSorted<T>(IEnumerable<T> values, bool descending = false) where T : IComparable<T>
{
    if (values == null) throw new ArgumentNullException(nameof(values));
    bool isFirst = true;
    T previous = default(T);
    foreach (T current in values)
    {
        if (!isFirst)
        {
            int comparison = previous.CompareTo(current);
            // Ascending fails when previous is greater, descending when previous is smaller
            if (descending ? comparison < 0 : comparison > 0) return false;
        }
        previous = current;
        isFirst = false;
    }
    return true;
}
Jedan prolaz, bez kopiranja i sortiranja. Za tekst pazi na poredjenje: string.CompareTo zavisi od kulture, a UI grid moze sortirati drugacije (velika/mala slova, srpska slova), pa test moze lazno pasti. Tada koristi isti IComparer kao aplikacija. Jednake susedne vrednosti su u redu (nije striktno).

Uporedi ocekivanu i stvarnu listu

Zadatak: Uporedi ocekivane vrednosti sa onim sto UI prikazuje i vrati sta nedostaje i sta je visak. Redosled i duplikati se ignorisu.

public static (List<string> Missing, List<string> Unexpected) CompareLists(IEnumerable<string> expected, IEnumerable<string> actual)
{
    var expectedSet = new HashSet<string>(expected);
    var actualSet = new HashSet<string>(actual);
    // Missing: expected but not shown. Unexpected: shown but not expected
    // Where keeps the order in which the items appear in the original lists
    var missing = expected.Where(item => !actualSet.Contains(item)).Distinct().ToList();
    var unexpected = actual.Where(item => !expectedSet.Contains(item)).Distinct().ToList();
    return (missing, unexpected);
}
Dobar QA odgovor vraca obe strane razlike, ne samo bool, jer poruka o gresci "nedostaje: A; visak: D" ubrzava debug. Ako redosled bitan, koristi SequenceEqual; ako su bitni duplikati, poredi brojeve pojavljivanja (zadatak "Prebroj duplikate").

Broj palih testova po suite-u (parsiranje loga)

Zadatak: Ulaz su linije oblika Suite|Test|Status. Vrati koliko testova je palo po svakom suite-u; neispravne linije preskoci. Ovo je mala verzija tvog jutarnjeg triage-a.

public static Dictionary<string, int> CountFailuresPerSuite(IEnumerable<string> lines)
{
    if (lines == null) throw new ArgumentNullException(nameof(lines));
    return lines
        .Select(line => line.Split('|'))
        // Skip malformed lines instead of crashing in the middle of a report
        .Where(parts => parts.Length == 3)
        .Where(parts => parts[2].Trim().Equals("Failed", StringComparison.OrdinalIgnoreCase))
        .GroupBy(parts => parts[0].Trim())
        .ToDictionary(group => group.Key, group => group.Count());
}
Suite bez padova se ne pojavljuje u rezultatu; ako izvestaj treba da ih prikaze, prvo grupisi sve linije pa broj palih racunaj unutar grupe. Ako se trazi rang, dodaj OrderByDescending(pair => pair.Value). Isti obrazac radi za tvoje .trx rezultate.

Retry pomocna metoda

Zadatak: Napisi generic metodu koja ponavlja akciju do zadatog broja pokusaja i vraca rezultat; ako svi pokusaji padnu, izuzetak se propagira.

public static T Retry<T>(Func<T> action, int maxAttempts, TimeSpan delay)
{
    if (action == null) throw new ArgumentNullException(nameof(action));
    if (maxAttempts < 1) throw new ArgumentOutOfRangeException(nameof(maxAttempts));
    for (int attempt = 1; ; attempt++)
    {
        try
        {
            return action();
        }
        // The filter is false on the last attempt, so the original exception propagates unchanged
        catch (Exception ex) when (attempt < maxAttempts)
        {
            Console.WriteLine($"Attempt {attempt} of {maxAttempts} failed: {ex.Message}");
            Thread.Sleep(delay);
        }
    }
}
Povezuje se sa flaky testovima (Sekcija 11): retry krije uzrok, pa se ponavlja samo za poznate prolazne greske (npr. StaleElementReferenceException), ne za svaki Exception, i uvek se loguje (Sekcija 19.7). catch ... when cuva originalni stack trace, za razliku od throw ex.

26.7 Testiranje sopstvenog resenja

Pre nego sto kazes da je zadatak gotov, predlozi ili napisi testove. To je ono sto QA inzenjera izdvaja od developera koji samo resi zadatak. Oblik iz tvog svakodnevnog rada:

public class ReverseStringTests
{

    [InlineData("hello", "olleh")]
    [InlineData("", "")]

    public void ReverseString_ReturnsExpected(string input, string expected)
    {

    }

    [Fact]
    public void ReverseString_Null_ThrowsArgumentNullException()
    {
        Assert.Throws<ArgumentNullException>(() => Solutions.ReverseString(null));
    }

Naziv testa prati konvenciju Method_State_Expected (Sekcija 19.4), [Theory] + [InlineData] pokriva vise ulaza jednom metodom (Sekcija 19.3), a Assert.Throws proverava da guard klauza radi.

26.8 Slozenost i potpitanja

SlozenostPrimer iz ovih zadataka
O(1)Pristup elementu niza po indeksu; Dictionary i HashSet Add/Contains (prosecno).
O(n)Jedan prolaz: CountVowels, FindDuplicates sa HashSet-om, TwoSum sa recnikom.
O(n log n)Sortiranje (OrderBy, Array.Sort); anagram poredjenjem sortiranih stringova.
O(n^2)Ugnjezdene petlje (naivno trazenje duplikata); += na stringu u petlji.
PotpitanjeOkvir odgovora
"Moze li brze?"Menjam memoriju za vreme: HashSet ili Dictionary umesto ugnjezdene petlje (FindDuplicates sa O(n^2) na O(n)).
"A sa manje memorije?"Resenje u mestu ili dva pokazivaca (ReverseManual, MoveZeroesToEnd). Ako je ulaz sortiran, duplikati se hvataju poredjenjem suseda.
"Sta ako je ulaz ogroman?"Proveri da je O(n), koristi StringBuilder umesto +=, i IEnumerable kad moze da se obradjuje redom, bez ucitavanja svega u memoriju.
"Case-insensitive? Unicode?"StringComparison.OrdinalIgnoreCase ili ToLowerInvariant; obrtanje po char-u lomi surrogate parove (emoji).
"Sta ako je ulaz null?"Guard klauza sa ArgumentNullException, ili prazan rezultat ako tako kazu zahtevi. Pitaj sta je ugovor metode.
"Kako bi ovo testirao?"Edge case-ovi iz 25.7 i xUnit Theory.
